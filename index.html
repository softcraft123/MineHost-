What is inside

Stated plainly: what works, what is proven, and what is not done yet.

Implemented

works today
  • Handshake, status, login, configuration, play
  • AES-128/CFB8 encryption (NIST vector), RSA exchange, Mojang session hash
  • Chunk generation, streaming, on-disk world persistence
  • Block break times, item drops, 36-slot inventory
  • Mobs with chase AI, health and combat
  • Chat, commands, whitelist, HTTP status dashboard
  • Fixed 20 TPS tick loop with metrics

Verified

evidence
  • 170 automated tests passing
  • Zero compiler warnings, formatted
  • AddressSanitizer: no memory errors
  • ThreadSanitizer: no data races
  • 2000 synthetic clients joined at 100%
  • ~0.47 MB per player at 1000 concurrent
  • Windows .exe executed and served players

Not done

honest
  • Not tested against a real vanilla client
  • Mojang live session server never contacted
  • No plugin or mod API
  • No IOCP backend (portable threads only)
  • Mobs have no pathfinding
  • Tools do not change break speed
